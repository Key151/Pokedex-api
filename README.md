# Pokédex API

Uma API back-end construída com Python e FastAPI que consome dados de personagens de jogos retrô (Pokémon) via PokéAPI.

## Objetivo
Este projeto é parte da trilha 7 Days of Code — Vibe Coding com Claude Code, onde construímos uma API do zero guiando um agente de IA como parceiro de programação.

## Como rodar
```bash
# Criar ambiente virtual
python -m venv venv

# Ativar ambiente virtual
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Rodar a aplicação
python app/main.py
```
